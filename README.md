# ai-demos
AI 生成的网页特效与小游戏 demo 合集

| Demo | 说明 |
| --- | --- |
| [深海波纹](water-ripple/index.html) | 用手指划过深海水面，激起会折射光线、带生物荧光的波纹。单文件，手机浏览器直接打开即可。 |
| [起雾的窗](fog-window/index.html) | 雨夜的城市隔着一扇起雾的玻璃：手指擦过的地方露出窗外街景，雨珠在玻璃上缓缓滑落，雾气过一会儿又慢慢蒙上来。单文件，手机浏览器直接打开即可。 |
| [亲手雕刻的南瓜灯](pumpkin-lantern/index.html) | 万圣节夜晚的木门廊上摆着一个写实南瓜：按住左键在南瓜上刻，刻穿的地方能看到壁厚和瓜瓤；右上角可一键刻笑脸、吓人脸、猫咪。单击南瓜点亮蜡烛，烛光闪烁着把脸投到地板和后墙上，再点一次吹灭、冒出一缕烟。右键拖动旋转、滚轮缩放，「重来」换一个新南瓜。单文件，Three.js 走 CDN，桌面浏览器直接打开。 |
